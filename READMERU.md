# Linux Net Ops

Этот репозиторий содержит исходный код, конфигурационные файлы и отчеты двух проектов, посвященных базовому администрированию Linux и настройке сетей. Проекты выполнены в рамках углубленного изучения DevOps и системного администрирования.

## Описание проектов

### DO1: Основы администрирования Linux (`DO1/src`)
Проект охватывает фундаментальные аспекты системного администрирования в Linux (Ubuntu Server). 
Ключевые темы и выполненные задачи:
- **Установка ОС и управление пользователями:** Развертывание ОС без графического интерфейса, создание пользователей и настройка прав `sudo`.
- **Базовая сеть:** Настройка статических и динамических IP-адресов через DHCP, настройка DNS и проверка связи с помощью `ping`.
- **Системные службы:** Настройка синхронизации времени (NTP) и управление сервисом SSHD (смена портов, анализ подключений через `netstat`).
- **Файловая система и диски:** Использование утилит `fdisk`, `df`, `du` и `ncdu` для управления и анализа дискового пространства.
- **Управление процессами и логами:** Мониторинг системных ресурсов с помощью `top` и `htop`, а также анализ системных журналов в `/var/log`.
- **Автоматизация:** Планирование задач с помощью `cron`.
- **Текстовые редакторы:** Продвинутое использование консольных редакторов, таких как `vim` и `nano`.

### DO2: Сети в Linux (`DO2/src`)
Проект углубляется в настройку сетей, маршрутизацию и безопасность с использованием виртуальных машин для симуляции реальной сетевой топологии.
Ключевые темы и выполненные задачи:
- **IP-адресация и подсети:** Расчет сетей и масок с использованием `ipcalc`.
- **Статическая маршрутизация:** Настройка сетевых интерфейсов через `netplan` и создание статических маршрутов между несколькими машинами и виртуальными роутерами.
- **Сетевая диагностика:** Измерение пропускной способности с помощью `iperf3`, трассировка маршрутов (`traceroute`) и анализ пакетов (`tcpdump`).
- **Настройка межсетевого экрана:** Реализация правил безопасности и фильтрации трафика с помощью `iptables`.
- **DHCP:** Настройка сервера `isc-dhcp-server` для динамической выдачи IP-адресов, включая жесткую привязку по MAC-адресу.
- **NAT:** Настройка SNAT и DNAT для маршрутизации внутреннего трафика во внешнюю сеть и проброса портов к внутренним сервисам (например, веб-серверу Apache).
- **SSH-туннели:** Настройка локального и удаленного проброса портов (TCP forwarding).

## Структура репозитория
- `DO1/src`: Исходные файлы, скрипты настроек и отчеты проекта по администрированию Linux.
- `DO2/src`: Исходные файлы, скрипты настроек и отчеты проекта по сетям в Linux.
